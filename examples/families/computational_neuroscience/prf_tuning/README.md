# Gaussian population receptive field (second example)

Written during the Milestone 2.5 agent dry run (`docs/FRICTION_LOG_M2_5.md`) as a brief-to-render exercise with a
topic different from the first example. The pRF model shown is the standard one-dimensional Gaussian over visual
field position with a centre and a size; the profiles in `data/prf_profiles.csv` are **computed from that
equation**, not measured, and the storyboard labels them so. No paper is included under `references/`.

It exercises what the first example does not: a `function_plot` with markers from a whitelisted expression,
relational placement (`below`), staged reveals within a scene (`reveal_at_seconds`), a `comparison_plot` without
point markers, and symbol subscripts (`x_0`).
